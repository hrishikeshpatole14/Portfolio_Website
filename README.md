# Professional Portfolio Website

A modern, fully responsive personal portfolio website built using plain HTML5, CSS3, and JavaScript. Designed with clean semantic elements, mobile-first responsiveness, and a built-in dark/light theme toggle.

## 🚀 Features
* **Semantic HTML5 Layout:** Structured using `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` tags.
* **Fully Responsive Design:** Optimized for mobile screens (`375px`), tablets (`768px`), and desktops (`1280px+`).
* **Interactive JavaScript Features:** 
  * Mobile navigation toggle menu.
  * Smooth scrolling navigation.
  * Dynamic Dark/Light mode theme toggle.
* **Zero Console Errors:** Clean, lightweight codebase with no broken links or external heavy frameworks.

---

## 🛠️ Built With
* **HTML5** — Page structure & layout
* **CSS3** — Custom styling, Flexbox, CSS Grid, and CSS Variables (Theming)
* **JavaScript (ES6+)** — Interactive UI states
* **Font Awesome** — Icons
